# AlinaWorld

**AlinaWorld** is an original 2D platformer for macOS starring **Alina**, a girl from the Lumen Isles who must reclaim twelve stolen Heart Crystals from the Night Crown across **36 missions** in four acts.

Inspired by classic side-scrolling platformer feel (acceleration, sprint, variable jump, stomp attacks) — not Nintendo assets or trademarks.

## Story

The Lumen Isles stay awake thanks to nine Heart Crystals. The Night Crown scatters them across nine worlds in three acts. Alina runs, jumps, and stomps through meadow, brook, grove, cavern, ridge, marsh, spire, storm, and the throne — one mission at a time until the finale.

## What's new in 2.0

- **Pixel-art everything** — Alina, Night Crown minions, tiles, items and scenery are drawn from character maps in `Game/Pixel/PixelCatalog.swift` and rendered crisp in both SpriteKit and SwiftUI.
- **Living worlds** — each of the nine worlds has its own banded sky, hill layers, trees and ambient weather (`Game/WorldTheme.swift`).
- **Bright storybook UI** — cream cards, chunky buttons and a shared pixel backdrop on every screen.
- **Stars** — every mission awards up to three: finish, beat par time, take no damage.
- **Power-ups** — bloom blocks hold the Sunbloom (shields a hit, breaks bricks) and the Glow Ribbon (hold jump to glide).
- **Real pause menu**, checkpoints, a results screen and a native **Settings** window (⌘,) with Assist mode.

## Controls (keyboard only)

| Key | Action |
|-----|--------|
| ← → or A D | Move (in-game) |
| ↑ ↓ ← → | Navigate menus / mission map |
| Shift | Sprint |
| Space, W, or ↑ | Jump (in-game) · press again in the air to double jump · hold while falling to glide with the Glow Ribbon |
| Enter | Confirm / start mission / next mission |
| F | Toggle fullscreen |
| Esc | Back / pause |
| ⌘ , | Settings |

## Requirements

- macOS 27+
- Swift 6.4+ toolchain (Xcode 27 or Command Line Tools)

## Build & run

```bash
chmod +x Scripts/build-app.sh
./Scripts/build-app.sh --open
```

The app bundle is created at `dist/AlinaWorld.app`.

Development build:

```bash
swift build
swift run
```

Jump straight to a screen while developing:

```bash
ALINA_START_ROUTE=play:8 swift run      # also: map, story:8, win:8, lose:8, play:8:paused
```

## Mission structure

- **27 missions** across 9 worlds (3 per world)
- Objectives: reach beacon, collect crystals, defeat guardians
- Difficulty ramps from Act I (easy) through Act III (hard, timed missions)
- Progress unlocks sequentially; stars, best times and petals are saved per mission
- Layouts are generated by `Scripts/generate-levels.py` (deterministic per `layoutSeed`); re-run it after changing the generator

## Project layout

- `Sources/AlinaWorld/App` — SwiftUI shell, routing, window setup
- `Sources/AlinaWorld/UI` — menus, map, briefing, HUD, pause, results, settings
- `Sources/AlinaWorld/Game/Pixel` — sprite catalog and pixel renderer
- `Sources/AlinaWorld/Game` — SpriteKit scene, physics, entities
- `Sources/AlinaWorld/Data` — missions, story, progress
- `Sources/AlinaWorld/Resources/Missions.json` — all level data
