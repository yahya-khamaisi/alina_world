# AlinaWorld

**AlinaWorld** is an original 2D platformer for macOS starring **Alina**, a girl from the Lumen Isles who must reclaim twelve stolen Heart Crystals from the Night Crown across **36 missions** in four acts.

Inspired by classic side-scrolling platformer feel (acceleration, sprint, variable jump, stomp attacks) — not Nintendo assets or trademarks.

## Story

The Lumen Isles stay awake thanks to twelve Heart Crystals. The Night Crown scatters them across twelve worlds in four acts. Alina runs, jumps, and stomps through the isles, then ventures beyond them to Frostpeak Hollow, Coral Lagoon, and Starfall Sky.

## Illustrated 2D refresh (macOS)

- **Sharp illustrated 2D art** — high-resolution Alina and creature animation sheets, painted scenery, detailed terrain, smooth icons and effects. The macOS renderer no longer draws the legacy character-map artwork.
- **Golden-hour meadow** — painted mountains, village and waterfalls scroll behind detailed flowers, bushes and terrain. Other worlds retain their own palettes and weather with antialiased scenery.
- **Illustrated world map** — twelve distinct islands, the real world names, a continuous route in mission order, a compass, and live mission/progress controls. Locked chapters can be previewed; playing still requires unlocking them.
- **Bright storybook UI** — a painted title scene, cream cards, pink buttons and responsive menu framing.
- **Animation** — matching idle, blink, run, jump, double jump, fall and glide poses with consistent scale and baseline.
- **Stars** — every mission awards up to three: finish, beat par time, take no damage.
- **Power-ups** — bloom blocks hold the Sunbloom (shields a hit, breaks bricks) and the Glow Ribbon (hold jump to glide).
- **Real pause menu**, checkpoints, a results screen and a native **Settings** window (⌘,) with Assist mode.

## Controls (keyboard only)

| Key | Action |
|-----|--------|
| ← → or A D | Move (in-game) |
| ↑ ↓ ← → | Navigate menus / mission map |
| Shift | Sprint |
| Space, W, or ↑ | Jump (in-game) · press again in the air to double jump · hold while falling to glide with the Glow Ribbon |
| Enter | Confirm / start mission / next mission |
| F | Toggle fullscreen |
| Esc | Back / pause |
| ⌘ , | Settings |

## Requirements

- macOS 27+
- Swift 6.4+ toolchain (Xcode 27 or Command Line Tools)

## Build & run

```bash
chmod +x Scripts/build-app.sh
./Scripts/build-app.sh --open
```

The app bundle is created at `dist/AlinaWorld.app`.

Development build:

```bash
swift build
swift run
```

Jump straight to a screen while developing:

```bash
ALINA_START_ROUTE=play:8 swift run      # also: map, story:8, win:8, lose:8, play:8:paused
```

## Mission structure

- **36 missions** across 12 worlds (3 per world)
- Objectives: reach beacon, collect crystals, defeat guardians
- Difficulty ramps from Act I (easy) through Acts III and IV (hard, timed missions)
- Progress unlocks sequentially; stars, best times and petals are saved per mission
- Layouts are generated by `Scripts/generate-levels.py` (deterministic per `layoutSeed`); re-run it after changing the generator

## Project layout

- `Sources/AlinaWorld/App` — SwiftUI shell, routing, window setup
- `Sources/AlinaWorld/UI` — menus, map, briefing, HUD, pause, results, settings
- `Sources/AlinaWorld/Game/Illustrated*` — high-resolution atlas, terrain and vector rendering
- `Sources/AlinaWorld/Game/Pixel` — shared sprite facade, legacy logical sizes and palette helpers
- `Sources/AlinaWorld/Resources/Art` — production paintings, transparent atlases and frame metadata
- `Sources/AlinaWorld/Game` — SpriteKit scene, physics, entities
- `Sources/AlinaWorld/Data` — missions, story, progress
- `Sources/AlinaWorld/Resources/Missions.json` — all level data

Art prompts, atlas orders and remaining platform work are documented in `design/art-v3/README.md` and `design/DEVELOPMENT_PLAN.md`. The Android TV port still uses its existing pixel renderer; the illustrated assets have not yet been ported to it.
